## 📦 System Variants Overview

### 🚀 Astrion Home Edition
The recommended system image for normal Astrion and Home Assistant operation.
* **Customized Launcher**: Optimized desktop layout for Astrion hardware.
* **UI & Performance Tweaks**: Smoother touch response and visual enhancements.
* **RosCard Ready**: Pre-installed and pre-configured RosCard system components.
* **Smart Home Environment**: Tailored specifically for Home Assistant control workflows.

### 🤖 Stock Android
The original factory Android system environment for Sanytron Astrion HA100.
* Pure Android framework without custom launchers.
* Ideal for Android application development, hardware testing, and custom ROM setups.

## 🚀 Flashing Guide & Developer Resources

> ⚠️ **Data Backup Warning:** Flashing system firmware will erase all user data. Please back up important files before proceeding.

### 🛠️ Drivers, Tools & Manuals
* 📖 **Flashing Manual & Drivers**: Download step-by-step PDF guides, MTK VCOM USB drivers, and Device ID restoration utilities at the **[Sanytron Developer Support Hub](https://hub.sanytron.com/support/astrion/developer)**.
* ⚡ **Flashing Utility**: Astrion HA100 uses **SP Flash Tool** (MediaTek's official free flashing utility).
* 🆔 **Device ID & SN Protection**: Always set SP Flash Tool to **`Download Only`** mode. Avoid using *Format All + Download* to prevent wiping NVRAM data (Device ID & Serial Number).
