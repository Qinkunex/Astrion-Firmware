# Astrion Firmware

Official firmware and system images for Sanytron Astrion HA100.

Astrion firmware releases are provided in two system variants:

## System Variants

### Stock Android

The original Android environment for HA100.

Recommended for:
- Android development
- Testing
- Custom applications
- Users who prefer the original system

### Astrion Home Edition

The Astrion-optimized Android environment.

Includes:
- Customized Astrion Launcher
- UI optimizations
- Pre-installed RosCard components
- Home Assistant integration components
- Astrion-specific system configuration

Recommended for:
- Home Assistant users
- Normal Astrion operation
- RosCard-based workflows
